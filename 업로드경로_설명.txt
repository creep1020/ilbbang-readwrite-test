읽기·쓰기 복습 v4 · 업로드 설명

GitHub 저장소: creep1020/ilbbang-readwrite-test
필수 업로드 파일 (정확히 3개):
1) /index.html (기존 파일 교체)
2) /readwrite/review.js (신규 파일)
3) /readwrite/review-stories.json (신규 파일, 이야기 원고 150편)

다음 파일은 유지: /readwrite/lessons.json, /readwrite/images/*, /characters/*, /sw.js, /manifest.webmanifest
원래 I-ll-bang-1 저장소에는 올리지 않습니다.

구현:
- 정규학습 영작 항목에 스스로 채점하는 맞았어요/다시 복습 버튼
- 새 표현 옆 어려워요 버튼
- 표시한 항목을 프로필별로 저장; 내일/3일/7일/14일/30일 간격 복습, 5회 성공 시 완료
- 오늘 복습과 전체 카드 보기
- 150편 원고 (5권×30편, 각 5문장 + 한국어). 그러나 DAY 1~2의 2편만 해당 학습 자료에 맞춰 확인 완료, 나머지 148편은 잠정 초안으로 교재 확인 후 승인해야 함
- 완료한 DAY 가운데 검수된 이야기만 랜덤 선택. 같은 날에는 동일 이야기, 가능하면 전날과 다른 이야기
- 지우/민서 선택 시 이름/대명사 변환, 학습자별 복습 기록 분리

제한:
- 오답 자동 채점이 아닙니다. 공책에 쓴 답을 스스로 확인합니다.
- 신규 복습 데이터는 기기 localStorage에 저장되며 다른 기기 Firebase 동기화는 아직 구현하지 않았습니다.
- 2~5권 원본 교재를 받지 못하여 148편의 사용 어휘/문법은 검수되지 않았습니다. 그래서 아이에게 자동 출제되지 않습니다.
- 별/성장/보상 패널 코드는 일절 변경하지 않았고 읽기·쓰기 완료 별 적립은 아직 미연동입니다.
- 삼성 기기에서 Firebase 계정 연동까지 실기기 검증된 버전은 아닙니다.
